# Spell Compendium v2 — Modular Pages and Curated Diagrams

## What this changes

The original \`/spells/\` search and College/School/spell selectors remain, but the reference is now reusable:
- \`src/components/SpellExplorer.astro\` owns the shared interface;
- \`src/styles/spells.css\` owns its styles;
- \`src/scripts/spell-app.mjs\` handles selection and rendering;
- \`src/scripts/spell-model.mjs\` contains shared sorting and URL helpers;
- \`src/pages/spells/[id].astro\` generates a canonical page per published spell;
- \`src/pages/spells/colleges/\` and \`src/pages/spells/schools/\` contain browseable indexes.

The selection controls remain available on **each** individual spell page. Choosing a different spell navigates to that spell's permanent URL. Spells are grouped by minimum level, then by name. The original \`/spells/\` entry point continues to work.

All content comes from the same \`src/data/spellbook.json\` generated by \`scripts/build-spellbook.mjs\` during \`prebuild\` and \`predev\`. **Nothing changes about the manual Google Sheets publish command, importer, or snapshot format.**

## Illustration workflow (future artwork)

The misleading automatically generated hex diagrams have been removed. Range and Area remain text fields populated by the spreadsheet. No illustration appears until specifically assigned.

When the artwork is ready:
1. Add an image in \`public/diagrams/\`, for example \`public/diagrams/three-meter-cone.png\`. Reuse the same image file for multiple spells if appropriate.
2. Edit \`src/data/spell-diagrams.mjs\`, adding a spell ID and one or both keys, \`range\` or \`area\`:
   \`\`\`js
   export const spellDiagrams=Object.freeze({
     "some-school-example-spell": { area:"diagrams/three-meter-cone.png" },
     "another-school-other-spell": { area:"diagrams/three-meter-cone.png" }
   });
   \`\`\`
   Those IDs are **examples only**. Use the actual spell IDs from the generated data.
3. Once assigned, the Range or Area value becomes a button that opens the illustration in a large closeable dialog.
4. The spreadsheet continues to control the written range/area statistics. Changing that value **does not automatically change the diagram**; assignments need deliberate review.

The diagram registry is intentionally separate from Google Sheets and the importer. The same diagram can be reused without copying image files into individual spell folders. No diagrams have been assigned yet.

## Important limitations

- The illustrations are not yet created.
- The new individual spell pages intentionally use the same spell detail interface as the catalog; separate elaborate spell artwork and School lore can come later.
- College and School index page introductions are still concise. Long-form lore belongs in future articles.
- The spell data importer remains the source of truth; future updates rebuild individual pages automatically.
